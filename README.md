# pelhaim

A model-agnostic board for running and watching AI coding agents: projects are train lines, agents are trains, planned tasks are stations, and questions arrive as alerts you can answer or dismiss. Visual language inspired by a classic subway control-room track board.

Status: design approved 2026-11-23; M1 (observe mode, board, alerts) in progress. See `docs/superpowers/specs/` once merged.
