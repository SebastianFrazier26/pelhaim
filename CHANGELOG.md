# Changelog

## Unreleased

- 2026-11-23: Workspace scaffold and CI.
- 2026-11-23: DECISION-LOG.md export: inserts a decision at the top of its project's Decided list (hash-checked atomic write, backup, idempotent per decision) and reads each project's open decisions.
- 2026-11-23: Read-only session-file tailer (complete lines only, CRLF-tolerant, resets on truncate/replace, reads at most 4 MiB per call) and a recursive home watcher with a poll tick.
- 2026-11-24: Board foundations: matte palette computed in OKLab from the film colours (plus film and high-contrast palettes), display list with platform-stable rounded coordinates, and a zoom/offset view with fit-to-viewport.
- 2026-11-24: Track board scene: project lines with open-decision and untested-format badges, block colours derived each frame (done behind, train in its state colour, cleared route ahead while working), platform bars that light on berth, 60° fork tracks, train tags with selection outline and a red outline for mis-tagged trains, "+N" stubs past 4 tracks, and folded idle lines.
- 2026-11-24: Board overlays: Maintenance-style alert popup (offset frame stack, kind tab, checkbox option rows, read-only rows for observed questions with Answer in terminal / Copy session id, Assign options with prefill highlight, project picker, result checklists, stalled status) anchored to the train's tag; alert tray (newest first, with ages); DISPATCH console strip (IME preedit, grows to 6 rows, radio-log notice cards, selected-train status, alert and unexported-decision counts, mode flags); AWAKE lamp with hover tooltip; and the zoom inset (zoomed board, state words, cwd, session id, stations, transcript tail, mis-tag slug).
- 2026-11-24: GPU renderer for the board's display list (wgpu): anti-aliased square-ended blocks and track strokes via an SDF shader, pixel-snapped glyph text, 4× MSAA triangles, scissor clips, exact sRGB colours; offscreen render plus pixel goldens (board, alert, inset, console) behind `--features gpu-goldens`.
- 2026-11-24: M1 Observe: `pelhaim` / `pelhaim observe` opens the board over live Claude Code and Codex sessions (read-only), with keep-awake, alerts, Assign, and `[Log decision]` export; `pelhaim doctor` checks CLI versions against the tested ones, config, data dir, decision log, keep-awake and GPU; `pelhaim decisions [--open]` prints logged and open decisions; `pelhaim --headless --dump-scene out.json` writes the board's display list. Unexported decisions export at startup.
- 2026-11-24: M1 fixes: untagged subagents of an orchestrator marked DISPATCH from its popup now land on UNSORTED with an Assign alert, as with `[dispatch].sessions`; terminal `AskUserQuestion` answers show and log only the answers (from `toolUseResult.answers`, else parsed from the harness sentence), bounded to 120 chars, with decision titles bounded to 160; the database uses WAL and a 5 s busy timeout, and a failed board write raises one "Board change not saved" alert; re-logging an alert-backed decision on a later day never duplicates its log entry; config rejects an empty project `name`/`log_section` or one with control characters or irregular spacing; `## Standing rules` and `## How to use this log` never match a project.
- 2026-11-24: Owner decision: the orchestrator draws no train. DISPATCH is a one-row strip, `DISPATCH · N agents running`; the orchestrator's subagents run only on their own project lines (no fork from DISPATCH), and its questions still raise popups and tray entries.
- 2026-11-24: Owner decision: stations come only from `pelhaim-milestone: <name>` marker lines in assistant text or prompts (Claude Code and Codex; own line, not in code fences, 32-char names, duplicates ignored). Prompts and tool calls no longer make stations; a train with no markers steps along one bounded leg. `[board].max_stations` (default 5) caps stations per track, folding older ones into "+N earlier".
- 2026-11-24: Owner decision: stations carry arrival times. A marker may end in `~20m` / `~1h30m` / `~45s`; the station the train runs to shows `ARR HH:MM` (local time), amber once overdue. Finished stations record estimate and actual seconds in SQLite (`station_timings`, schema v2, numbers only) and later ETAs use the median actual/estimate ratio (newest 20, per project from 5 samples, else global, else 1, clamped 0.25–8).
- 2026-11-24: Owner decision (partly reversing 2026-11-23): sessions auto-register to a project from where they run. After an Assign answer and tags, an untagged session goes to the line of the git repository its cwd lies in, read from `.git` only (linked worktrees resolve to the main repository; symlinks followed; cached per directory; no git process, no writes). It matches a `[[project]]` by `path` or slug; otherwise a line is created for it named after the repository, as for a tag with an unconfigured slug. UNSORTED and its Assign alerts are now only for sessions with no tag and no repository. `[board].auto_projects = false` restores tags-only placement.
- 2026-11-24: Decisions logged from an auto-created line now export to `DECISION-LOG.md` under the line's display name (e.g. `## SafeAscent`; `cabn` matches `## cabn and the portfolio`), with the same heading rules, byte-preserving insert and idempotent markers as configured projects. A missing section is created; a missing log file still fails.
- 2026-11-24: App icon: the front of a metro car with a glowing red LED "1" (the board font's glyph) in a ring on its forehead, drawn by `cargo run -p pelhaim-board --example icon` (hand-tuned 16 and 32 px grids) into `assets/icon/` with a `pelhaim.icns`. `scripts/bundle-macos.sh [--install]` builds an ad-hoc-signed `target/pelhaim.app` that opens `pelhaim observe`; on Linux and Windows the window carries the icon.
- 2026-11-25: App icon: the LED "1" now has a bold diagonal flag and no foot so it cannot read as an "L" (icon only; the board font is unchanged), at every size including the 16 and 32 px grids.
